Open Documents → Complete Canvas Lab Handbook for all scenarios, inputs, outputs, flow and step tabs, native control inventories, Groovy debugging and Git/UAT/PROD guidance. It supersedes the historical baseline readiness notes and the original five-flow review scope.

Run an exercise

  1. Configure ScenarioId using an ID below, save and Deploy. Timer lessons run once.
  2. Check Monitor Message Processing: TRN_ScenarioId, TRN_Expected and TRN_TestResult. Negative/end lessons deliberately finish FAILED or ESCALATED.
  3. Use Simulation for full JSON reports; use live runtime for persistence, ProcessDirect, end states and aggregation.
  4. Deploy receivers 049 and 053 before their callers. Aggregator 053 is driven and verified through 057 using a unique batch ID and ExpectedBatchId.

Security: synthetic fixtures only; training keystore aliases must be provisioned separately. No credentials/private keys are in Git.

Git: sap-cpi-training-canvas-examples. Native SAP Git Access still needs its separate dedicated credential and repository association in Settings → Integrations → Git Access.
